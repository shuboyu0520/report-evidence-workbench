如何判分

每份文件先固定 14 道查数、4 道未披露年度题及原件 SHA-256，随后通过同一工作台 API 上传 PDF、调用本地 Qwen3 4B 和向量模型。查数要求前五条证据包含指定物理页的原行，回答同时给对年度、金额、百万美元单位和原表页码。混合期间报表还要求答清单季、累计、全年或指定日期。拒答只接受“未披露”，可带句末标点。

严格通过数按原定字段自动判定。Apple 两道期末余额题给对了日期、金额和页码，但把时点余额又描述为“全年期间”；这属于回答表述缺陷。结果适用于这三份 PDF 的固定问题。下方逐题展示用户看到的原答。
