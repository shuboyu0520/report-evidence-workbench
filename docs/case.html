Agent 在哪一步作决定

提问先核对研究日期和报告期。已核准案例用向量检索找证据卡，由模型选择卡片；新上传的英文业绩表先定位集团或分部、财务期间和原行，金额由程序按列读取，其他问题按页检索。未到期的实际值由日期判定，检索结果不足则说明缺证。公司、同行、市场和政策分别取证后，汇总草稿再核对数字及来源。
