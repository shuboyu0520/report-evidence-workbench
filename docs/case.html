同一份财报，两种阅读任务

初学者先看经营收现、资本开支分别发生了什么；投资者展开期间、币种、原页和比较口径。两个视图共享同一组数据。切换研究日期时，系统只选当时已发布的同行和行业资料。

Agent 在哪一步作决定

提问先核对研究日期和报告期。已核准案例用向量检索找证据卡，由模型选择卡片；普通上传报告按原页检索，模型提取数字与引文。未到期的实际值由日期判定，检索结果不足则说明缺证。公司、同行、市场和政策分别取证后，汇总草稿再核对数字及来源。
